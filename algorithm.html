1. Go / No-Go decision chain

The verdict is computed in fixed order. The first failing check determines a NO-GO; conditions are added without failing the trip.

#CheckRuleFailure effect
1Tide windowBest low-tide exposure on the selected date ≥ 2.5 hours (from the region's sample tide set)NO-GO
2SwellSignificant wave height ≤ 1.5 m (Galicia sample) / ≤ 1.8 m (BC sample)NO-GO

4Harvest limiterSuggested take = min(planned, 80% × region quota headroom)Condition (cap)
5Wind> 20 kn adds a caution flagCondition (flag)

No hidden weights. Each rule is a single, stated threshold. Verdicts are planning guidance for a qualified human — not a marine-safety assessment, not a legal determination.

2. Tide-window logic

Each date carries a sample set of low tides with exposure hours. The engine takes the maximum exposure low for the selected date and compares it to the 2.5-hour threshold.

best = max(exp over lows(date)) · tideOK = best.exposure ≥ 2.5

Rationale: sub-2.5-hour windows compress the safe working interval on exposed rock to the point that the trip often becomes a dead run — a hypothesis to test in the pilot, not a validated claim.

3. Site suitability score (public weights)

score = round(100 × (0.45·density + 0.35·(5−risk)/4 + 0.20·permitFactor))

FactorWeightMeaningStatus
Density0.45Sample survey estimate of harvest-size barnacle densityIllustrative, not field-validated
Access risk0.35Wave exposure / terrain difficulty (1 = sheltered … 5 = extreme)Expert-style sample value
Permit factor0.20Open = 1.0 · Managed-with-licence = 0.85 · Restricted = 0From sample rule set

The score is a comparison aid between sites in the same region. It is not a measure of legal access, safety, or yield.

5. Harvest limiter

suggestedTake = min(plannedTarget, 0.8 × regionQuotaHeadroom)

The limiter never raises a take above what the operator planned. It only caps. The 80% factor reserves headroom against uncertainty in scale-weight vs landing-weight and density variation. Whether this factor is the right one is a pilot question — the rule is public so it can be challenged.

Gooseneck barnacle fisheries are documented as susceptible to overharvest without adaptive management (Oregon Sea Grant ORESU-S-17-002; NOAA repository noaa_35095_DS1.pdf). The limiter is designed to support restraint — its ecological effect is a hypothesis to test, not a claim.
